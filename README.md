# Local LLM Video RAG System

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![Ollama](https://img.shields.io/badge/Ollama-local-green)
![ChromaDB](https://img.shields.io/badge/ChromaDB-Vector_Store-orange)

![License](https://img.shields.io/badge/license-MIT-blue)

A fully local **Retrieval-Augmented Generation (RAG)** pipeline for semantic question answering over video content. Videos are transcribed, chunked, embedded, indexed into **ChromaDB**, and queried entirely offline using local LLMs — no external APIs required. Includes an automated **RAGAS** benchmarking suite to quantitatively measure retrieval and generation performance.

---

## Tech Stack

| Tool | Purpose |
|---|---|
| **FFmpeg** | Video to MP3 audio extraction |
| **OpenAI Whisper** | Speech-to-text transcription with timestamps |
| **Ollama (`nomic-embed-text`)** | 768-dimensional local embedding generation |
| **ChromaDB** | Persistent vector database with HNSW cosine similarity search & metadata storage |
| **Ollama (`mistral:7b`)** | Local large language model for conversational, timestamped responses |
| **Ragas** | Automated RAG evaluation framework (Recall, Precision, Relevancy, Faithfulness) |

---

## Architecture & Pipeline

```
[Raw Video Files (.mp4)]
           │
           ▼ (ffmpeg)
    [Audio (.mp3)]
           │
           ▼ (Whisper)
[Timestamped Transcripts]
           │
           ▼ (Segment Grouping - 5 segments/chunk)
   [Contextual Chunks]
           │
           ▼ (Ollama nomic-embed-text)
[Embeddings + Metadata] ──► [Persistent ChromaDB (HNSW Index)]
                                         │
[User Query] ──► [Query Embedding] ──────┤ (Cosine Similarity Search)
                                         │
                                         ▼
                               [Top-K Video Chunks]
                                         │
                                         ▼
                             [Mistral 7B (Ollama)]
                                         │
                                         ▼
                        [Timestamped & Guided Answer]
```

## Evaluation & Benchmarks (RAGAS)

The system is evaluated against an automated benchmark suite (`Data/eval_dataset.json`) across all course modules using **Ragas** with local Ollama evaluators (`mistral:7b` as judge LLM and `nomic-embed-text` as embeddings):

| Metric | Score | Target | Evaluation Status | Description |
| :--- | :---: | :---: | :---: | :--- |
| **Context Recall** | **`1.0000`** (100.0%) | $\ge 0.80$ | 🟢 **Perfect** | All ground-truth knowledge was successfully retrieved by ChromaDB. |
| **Context Precision** | **`0.8866`** (88.7%) | $\ge 0.75$ | 🟢 **High** | Highly relevant video chunks are consistently ranked at top positions. |
| **Answer Relevancy** | **`0.7946`** (79.5%) | $\ge 0.80$ | 🟢 **Strong** | Generated answers directly address the student's question without drifting. |
| **Faithfulness** | **`0.6979`** (69.8%) | $\ge 0.85$ | 🟡 **Moderate** | Grounded in context; variance stems from conversational friendly persona instructions. |

To re-run the benchmark suite:
```bash
python Pipeline/evaluate_rag.py
```

## How to Run

### 1. Prerequisites
- Python 3.10+
- [FFmpeg](https://ffmpeg.org/download.html) installed and added to your system PATH.
- [Ollama](https://ollama.ai/) running locally with the required models:

```bash
ollama pull nomic-embed-text
ollama pull mistral:7b
```

### 2. Install Dependencies
```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 3. Quick Start (Windows)
```cmd
Pipeline\run_pipeline.bat
```

### 4. Manual Execution
Run the scripts in order:
```bash
python Pipeline/mp3_Conversion.py
python Pipeline/Speech_To_Text.py
python Pipeline/create_chunks.py
python Pipeline/new_Chunks.py
python Pipeline/readChunks.py
python Pipeline/processing_Query.py
```

After `processing_Query.py` starts, enter your question in the CLI. The system retrieves the most relevant video chunks and generates a warm, friendly response guiding you to the exact video and timestamps.

## Chunking Strategy & Retrieval Logic

* **5-Segment Grouping:** Whisper's default transcript segments are often very short (sometimes single words). Grouping 5 consecutive segments preserves semantic context while keeping chunk granularity focused.
* **Vector Indexing:** Stored persistently in ChromaDB using `hnsw:space: "cosine"`. This provides sub-millisecond retrieval across hundreds of hours of video transcripts without loading large files into memory.
* **Metadata Schema:** Each chunk retains `Title`, `video_number`, `start_time`, and `end_time` allowing the LLM to provide precise time ranges (e.g. `00:45 - 01:00`).
